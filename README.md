# anotherME

Anonymous social platform focused on privacy and meaningful discussions.

## Stack

* Frontend: React, Vite, Tailwind CSS
* Backend: Node.js, Express, MongoDB

## Getting Started

### Backend

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

## Environment

Configure the required variables in `.env` files. See `.env.example` for details.

## Project Structure

```text
anotherME/
├── frontend/
├── backend/
└── docs/
```

## Features

* Anonymous accounts
* Posts and comments
* Communities (Circles)
* Content reactions
* Responsive UI
