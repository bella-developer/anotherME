# ESO

A dark aesthetic social platform for introverts and deep thinkers.

## Stack

* React + Vite
* Node.js + Express
* MongoDB
* Tailwind CSS

## Setup

Backend:
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

Frontend:
```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```
