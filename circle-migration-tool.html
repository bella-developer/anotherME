🔧 Circle Room Migration Tool

Assign room types to your circles so badges appear correctly

Step 1: Check Current Status

See which circles have room assignments and which don't.

Step 2: Auto-Migrate Circles

Automatically assign rooms based on circle names and categories.

Step 3: Manual Assignment (Optional)

Manually assign a room to a specific circle.

📋 Instructions

  1. Make sure your backend server is running (npm run dev)
  2. Make sure you're logged in to the application
  3. Click "Check Circle Status" to see current state
  4. Click "Run Auto-Migration" to automatically assign rooms
  5. Use manual assignment for any circles that weren't auto-assigned
  6. Refresh your Circles page to see the badges!
